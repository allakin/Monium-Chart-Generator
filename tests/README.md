# Тесты плагинов Monium Chart Generator

Автоматические тесты гоняют **настоящий `code.js`** каждого из пяти плагинов внутри
Node-песочницы, подключённой к моку Figma Plugin API, и проверяют построенное
дерево нод. Логика `ui.html` проверяется так же — скрипт плагина поднимается в vm
с минимальным DOM и виртуальными таймерами. Зависимостей нет — только встроенный
`node:test` (нужен Node ≥ 20).

## Запуск

```bash
npm test                 # все файлы
npm run test:pie         # только Chart Pie
npm run test:sizes       # только матрица размеров фрейма
npm run test:watch       # перезапуск при правках

node --test tests/pie.test.js                        # один файл
node --test --test-name-pattern "legend" tests/*.test.js   # по имени теста
```

`node --test tests/` (директорией) в Node 25 не работает — передавайте glob
`tests/*.test.js`, как в npm-скриптах.

Итог сейчас: **1118 тестов, 1109 проходит, 9 помечены `todo`** (это
задокументированные баги, см. «Известные баги» ниже). Полный прогон ~1.2 с.

## Устройство харнесса

```
tests/helpers/
  figma-mock.js    мок Figma Plugin API: нод-дерево, createX, group, ui, notify
  load-plugin.js   загрузка code.js в vm + handle для управления как из UI
  load-ui.js       загрузка скрипта ui.html в vm + мини-DOM и виртуальные таймеры
  inspect.js       обход дерева и переиспользуемые проверки
  axis.js          общие проверки для осевых чартов (line/area/bar)
  color.js         независимая реализация OKLab ΔE и симуляции дальтонизма
  fixtures.js      эталонные payload'ы, размеры фреймов, наборы опций
```

Типичный тест:

```js
const h = loadPlugin('pie', { seed: 42 });   // seed → воспроизводимый «рандом»
const frame = h.selectFrame(233, 95);         // создать и выбрать фрейм
await h.generate(payload('pie', { showLabels: true }));
const container = h.chart();                  // фрейм "Chart Pie"
assert.equal(layerItems(container, 'Slices').length, 5);
```

Полезное на `handle`: `generate()`, `paste()`, `send()`, `selectFrame()`,
`select()`, `clearSelection()`, `charts()`, `chart()`, `chartParams()`,
`lastSelectionMessage()`, `errorNotifications()`, `reseed()`, `global`
(доступ к `var`-ам и функциям плагина), `log` (уведомления, сообщения в UI,
прыжки вьюпорта).

### Мок строг там, где плагины реально ломаются

- `resize()` отвергает размеры < 0.01 и нечисловые — **именно так ловится баг
  «график не отображается»**: отрицательная площадь построения падает с
  исключением, а не рисуется молча.
- `LINE` можно ресайзить только с высотой 0.
- `arcData` требует конечных углов и `innerRadius` в диапазоне 0…1.
- `vectorPaths` отвергает NaN/Infinity в координатах.
- `TEXT` не даёт писать `characters`/`fontName` до `loadFontAsync()`.
- `createX()` вешает ноду на текущую страницу, поэтому забытые измерительные
  ноды видны как «мусор на странице».
- `ui.postMessage` делает structured clone, как настоящая граница plugin↔UI.
- Мок читает `manifest.json` плагина: при `documentAccess: "dynamic-page"`
  синхронный `figma.getNodeById` бросает ошибку, как в Figma, — работает только
  `getNodeByIdAsync`. Плагины хранят ссылку на последний выбранный фрейм, а не
  его id; `harness.test.js` дополнительно запрещает вызов `getNodeById(` в коде.

### Приближения мока — на них нельзя опираться в ассертах

- **Метрики текста** — таблица ширин символов, а не настоящий Inter. Ширины
  пропорциональны и стабильны, но не пиксель-в-пиксель. Проверяйте отношения
  («длиннее подпись → больше отступ»), а не абсолютные значения.
- **Вектор** — `x/y/width/height` берутся из bbox данных пути.
- **Поворот** учитывается только для `LINE` на ±90° (вертикальные линии сетки);
  другие повороты игнорируются.
- **Группы** считают bbox один раз, в момент `figma.group()`. Плагины не двигают
  детей после группировки; если это изменится, боксы устареют.
- **Координаты детей группы** в моке отсчитываются от группы, а в Figma — от
  ближайшего фрейма. Код, сравнивающий позиции слоёв из разных групп, должен
  брать `absoluteBoundingBox` (он есть и в моке, и в Figma), а не `x`/`y`.
- **`pluginData` в моке общий** для всех плагинов, а в Figma он у каждого
  плагина свой (по `id` из `manifest.json`): график сводного генератора
  отдельный плагин видит только через разбор слоёв. Такой случай тест должен
  моделировать сам — стереть `chartParams` перед чтением.
- Значения, присвоенные кодом плагина, живут в другом realm — `assert.deepEqual`
  с хостовым литералом падает на прототипе. Оборачивайте в `plain()` из
  `inspect.js`.

## Известные баги (помечены `todo`)

Эти тесты описывают **правильное** поведение и помечены `todo`, поэтому прогон
остаётся зелёным. Когда баг починят, они станут проходить — тогда снимите
маркер.

1. **Отрицательная площадь построения на маленьких фреймах** — Line, Area, Bar
   (оба плагина). `plot.h = h − 10 − 21 − легенда` и `plot.w = w − padLeft − 2`
   уходят в минус, `drawGrid*` вызывает `resize()` с отрицательной длиной →
   исключение, пустой фрейм. Падает от ~160×60 с легендой и от 60×24 без.
   Pie уже исправлен: маржины масштабируются от фрейма, диаметр ограничен снизу.
   → `small-frames.test.js`
2. **Молчаливый провал рендера** — standalone Line, Area, Bar.
   `figma.ui.onmessage` не ловит ошибки, промис отклоняется в пустоту,
   пользователь видит пустой фрейм без объяснений. В Pie и в сводном
   генераторе есть try/catch с `figma.notify(..., { error: true })`.
   → `small-frames.test.js`
Исправлено вместе с пикером цветов (маркеры `todo` сняты):
- легенда в режиме Normal у отдельного Chart Bar больше не дополняется до
  запрошенного `barsCount` → `bar.test.js`;
- горизонтальный Bar без `pluginData` теперь распознаётся и в отдельном
  плагине, и в сводном генераторе (ориентация определяется по столбцам)
  → `layer-parsing.test.js`.

## Как добавить тест

1. Опция чарта → в сьюту своего типа (`pie.test.js` и т.д.), рядом с похожими.
2. Новая чистая функция → `helpers-unit.test.js`, и, если она есть в нескольких
   плагинах, добавьте её в `DRIFT_CASES` — это ловит расхождение копий.
3. Новый размер фрейма или набор опций → `fixtures.js` (`SIZES`) или `COMBOS` в
   `small-frames.test.js`: дальше он автоматически попадёт в матрицу.
4. Поведение UI (кнопки, состояния блоков, сообщения в плагин) → отдельная сьюта
   на `loadUI` из `load-ui.js`, как `copy-loader.test.js`. Мини-DOM отдаёт только
   элементы с `id` из самого `ui.html`, а таймеры виртуальные: `ui.clock.tick(ms)`.
4. Ассерты пишите к наблюдаемому результату (дерево нод, `chartParams`), а не к
   внутренностям — так тест выживает при рефакторинге и ловит расхождения между
   отдельными плагинами и сводным.

Того, что мок проверить не может (реальная отрисовка, вёрстка и анимации в
iframe, высота окна плагина, шрифты), касается ручной чек-лист: `MANUAL_QA.md`.
UI-сьюты проверяют логику скрипта, но не то, как он выглядит.
