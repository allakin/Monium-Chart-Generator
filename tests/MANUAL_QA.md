# Ручной чек-лист: проверка плагинов в Figma

Автотесты (`npm test`) закрывают логику построения дерева нод. Здесь — то, что
проверяется только в живой Figma: настоящая отрисовка, окно плагина, буфер
обмена, шрифты, undo. Проходить полностью перед релизом; при правке одного
плагина достаточно его раздела + разделов «Общая механика» и «Регрессии».

Формат: `[ ]` — не проверено, `[x]` — ок, `[!]` — расхождение (опишите под
пунктом: что сделали, что ожидали, что получилось, размер фрейма).

## 0. Подготовка

- [ ] В Figma: Plugins → Development → Import plugin from manifest…, добавить
      каждый из пяти `manifest.json` (Chart Line / Bar / Area / Pie / Monium all
      charts generator).
- [ ] Открыть консоль разработчика (Plugins → Development → Open console) —
      держать открытой всю сессию: любой красный трейс в ней считается `[!]`,
      даже если график нарисовался.
- [ ] Тестовый файл: страница с фреймами 1200×800, 600×400, 400×300, 233×95,
      160×60, 60×24, 40×40 и одним фреймом Auto Layout.

## 1. Общая механика окна плагина

Для каждого плагина:

- [ ] Плагин открывается, окно шириной 300 px, содержимое не обрезано.
- [ ] Окно само подстраивает высоту под содержимое (разверните/сверните секции).
- [ ] Без выделения: показана кнопка вставки, нет надписи о целевом фрейме.
- [ ] Выделили фрейм → в шапке его имя и размер, размер совпадает с панелью
      Figma.
- [ ] Выделили фрейм с уже вставленным графиком → появились Regenerate и Copy,
      кнопка Insert выключена.
- [ ] Сняли выделение → Regenerate и Copy скрылись, Insert снова активна.
- [ ] Выделили не фрейм (текст, картинку, группу) → плагин не предлагает
      целевой фрейм и не падает.
- [ ] Ввели мусор в числовые поля (`abc`, `-5`, `999`, пусто) → плагин
      подставляет дефолт или клэмпит, ничего не ломается.
- [ ] После вставки в консоли нет ошибок, на странице нет лишних текстовых нод
      рядом с графиком.

## 2. Вставка и замещение

- [ ] Без выделения → график падает на страницу: Line/Bar/Area 600×400,
      Pie 500×500, вьюпорт прыгает к нему.
- [ ] Пустой фрейм выделен → график вставлен внутрь, занимает фрейм целиком,
      в слоях появился фрейм `Chart <Тип>`, тост «Chart added to "<имя>"».
- [ ] Regenerate → старый график исчез, новый на том же месте, тост
      «Chart regenerated!». Второго графика в слоях нет.
- [ ] Выделили сам фрейм `Chart <Тип>` → Regenerate перерисовывает его
      содержимое, сам фрейм остаётся тем же (не появляется вложенный).
- [ ] Целевой компонент (COMPONENT) и его инстанс (INSTANCE) — график
      вставляется внутрь и занимает весь размер.
- [ ] Фрейм с Auto Layout — график вставляется, Auto Layout не растаскивает
      слои (при необходимости зафиксируйте поведение в `[!]`, автотесты этого
      не воспроизводят).
- [ ] Сводный генератор: в одном фрейме сделали Pie → переключили вкладку на
      Line → Regenerate. Остался один график, называется `Chart Line`.
- [ ] Undo (⌘Z) после вставки убирает график целиком, файл остаётся рабочим.

## 3. Копирование и вставка между фреймами

- [ ] Copy на готовом графике → тост про скопированный график, в окне плагина
      появился блок буфера с описанием.
- [ ] Выделили другой фрейм → Paste → график воспроизведён **точно**: те же
      значения, те же цвета серий, те же полоски событий.
- [ ] Вставка в фрейм другого размера → пропорции пересчитаны, данные те же,
      подписи не наезжают друг на друга.
- [ ] Вставка в фрейм с уже существующим графиком → он заменён, а не наложен.
- [ ] После Paste поля формы заполнились значениями вставленного графика
      (можно сразу редактировать).
- [ ] Скопировали stacked Area с включённым fill-to-height → после вставки
      высота стека такая же, а не в разы меньше.
- [ ] Перезапустили плагин → буфер пуст (это ожидаемо), Paste не предлагается.

## 4. Chart Line

- [ ] 6 подписей X, 5 делений Y, 3 линии: сетка ровная, линии не выходят за
      область построения, обводки толщиной 2.
- [ ] Стили Smooth / Sharp / Peak визуально отличаются; Smooth не «вылетает»
      выше верхнего деления и ниже нижнего.
- [ ] Peak: видны редкие пики на низком базовом уровне, линия не превращается
      в кашу.
- [ ] Единица измерения (`ms`, `%`, ` req/s`) приписана ко всем делениям Y,
      область построения сдвинулась вправо ровно настолько, сколько нужно.
- [ ] Время в делениях (`0:00, 1:30, 3:00`) — подписи выводятся как введены.
- [ ] 20 линий — цвета различимы, ни одна не выглядит чёрной.
- [ ] Легенда: маркер-линия 14×2, выравнивание left/center/right работает,
      длинные подписи обрезаны с «…», при >3 рядов появился пагинатор.
- [ ] Полоски событий сверху и снизу не перекрывают область построения.

## 5. Chart Area

- [ ] Overlap: все области доходят до базовой линии, полупрозрачны, видно
      наложение.
- [ ] Stacked: области лежат друг на друге без зазоров и разрывов, верхняя
      кромка нижней области точно совпадает с низом верхней.
- [ ] Stacked + Fill to height: стек упирается в верх области построения.
- [ ] Прозрачность 0.05 / 0.3 / 1 — визуально различается, тонкая обводка
      областей на месте.
- [ ] Sharp/Smooth/Peak в обоих режимах стекинга не дают самопересечений.

## 6. Chart Bar

- [ ] Normal: по одному столбцу на категорию, все стоят на базовой линии.
- [ ] Grouped: столбцы внутри категории разного цвета, с зазором 1 px, группа
      по центру слота.
- [ ] Stacked: сегменты стоят друг на друге без щелей, суммарно не выходят за
      верх области.
- [ ] Dense: десять узких столбцов на категорию, они не слипаются в одно
      пятно.
- [ ] Bar gap 0 / 1 / 10 — столбцы соответственно смыкаются и расходятся.
- [ ] Horizontal: категории слева, значения снизу, столбцы растут от левого
      края, длинные названия категорий не обрезаны.
- [ ] Horizontal + Stacked: сегменты в каждой строке идут цепочкой слева
      направо без щелей.

## 7. Chart Pie

- [ ] Donut и Pie: первый сектор начинается на 12 часах, сектора идут по
      часовой стрелке в порядке значений.
- [ ] Inner radius 30 / 55 / 80 — дырка меняется соответственно.
- [ ] Corner radius 0 / 12 / 50 — скругление применяется только к donut.
- [ ] Segment gap 0 / 1 / 10 — зазоры равномерные; при gap 10 и мелких секторах
      мелкие исчезают, остальное рисуется.
- [ ] Show value labels: выноски не пересекают друг друга на средних размерах,
      подписи читаемы и не вылезают за фрейм.
- [ ] Show center total: сумма по центру, помещается в дырку, не перекрывает
      сектора.
- [ ] Легенда: маркер-точка 8 px, не наезжает на пирог; сам пирог уменьшился,
      чтобы освободить место.
- [ ] Значения `10, 0, 20` — нулевой сектор не рисуется, остальные корректны.
- [ ] Все значения нули → пустой фрейм без ошибок в консоли.

## 8. Регрессии (обязательно)

- [ ] **233×95, Pie, Display: Show value labels + Show center total** — пирог

- [ ] 233×95 для Line, Area, Bar — рисуется.

- [ ] 60×24 и 40×40, все типы — то же самое: Pie должен рисоваться, остальные

      график сделан старой версией) → выделить фрейм — **известный баг**:
      плагин не распознаёт график, Regenerate/Copy не появляются.
